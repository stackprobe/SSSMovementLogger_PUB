# ぐうたら日和

スマホの足あとを眺めながら、PCの前から動きたくない女子「こもり」が、あなたの移動や滞在について話す趣味・ジョークアプリです。

こもりをタップすると、薄紫の吹き出しでひとこと。よく動いた日も、同じ場所でのんびりした日も、こもりと一緒に振り返れます。

## はじめかた

Android 12以降のARM64端末で利用できます。Google Play開発者サービスが必要です。APKの導入方法は [インストール手順](Build-and-Install.md#インストール) を参照してください。

1. アプリを開き、設定の「権限を設定」から位置情報を「常に許可」にします。おおよその位置でも利用できます。
2. アプリに戻ると、足あとの記録が自動で始まります。
3. しばらく過ごしてから、こもりをタップしてみてください。直近3時間の足あとをもとに話します。記録が少ないときは、もう少し待ってみてください。

## こもりからの通知

移動を始めたり、移動後にひと休みしたりすると、こもりが話しかけることがあります。

通知は初期設定ではオフです。使いたい場合だけ、設定の「こもりからの通知」をオンにして、通知を許可してください。オフにすると、表示済みのこもりの通知も消えます。「記録中」などの通知は出しません。

## 足あとの記録

位置情報と会話の処理は端末内で行い、位置情報をサーバーには送りません。記録には誤差や抜けがあり、反映が遅れることもあります。スマホの位置の変化を見ているため、歩数や歩いた距離を正確に測るものではありません。

設定から記録を開始・停止できます。ただし、位置情報の権限がそろっていれば、アプリを起動したときや設定画面を開き直したとき、端末の再起動・アプリの更新後には自動で記録を再開します。

足あとは自動で削除されず、端末の空き容量を使って保存されます。停止しても記録は残ります。消したいときは、設定の「足あとをすべて消す」を選んでください。確認後に全履歴を削除し、元には戻せません。設定は残り、記録中ならその後の足あとを引き続き記録します。停止中なら停止したままです。

アンインストールやアプリのデータ消去でも記録は消えます。記録は端末のバックアップ対象には含まれません。
