# 実装と確認

0.6.0ではシステム通知を出さない記録方式に変更しました。現在の仕様は [設計](Design.md)、開発・編集方法は [開発ガイド](Development.md) を参照してください。

自動テストは、他アプリ形式の拒否・保全、4,320件超の保存、30日後の復元、停止後の保持、重複・不正点の除外、不完全追記の回復、移動・静止・欠測の判定、セリフの読込・置換、移動状態の変化、遅れて配信された測位の採用を確認します。

実機で確認する項目：吹き出しの視認性、簡素化した設定画面、通知オフ時の非表示、通知オン時の移動変化のセリフ、権限の拒否・許可、バックグラウンド測位の配信頻度、再起動・更新後の再登録。
